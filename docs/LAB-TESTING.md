# رویهٔ تست آزمایشگاهی (اختیاری، فقط روی تجهیزات آزمایشگاهی)

هدف: راستی‌آزمایی فرمت خروجی‌ها و ترجمه‌ها روی نرم‌افزار واقعی. **هرگز روی تجهیزات تولیدی.**

1. در PNETLab/ESXi: Cisco IOSv/IOSvL2/CSR1000v، MikroTik CHR (6.49 و 7.x)، FortiGate-VM (آزمایشی). در هر کدام کاربر SSH و IP مدیریتی بسازید؛ از روی PC به شبکهٔ مدیریتی لب دسترسی بدهید.
2. برنامه را **بدون** `NC_ENABLE_SIMULATOR` اجرا کنید؛ دستگاه SSH واقعی اضافه، کلید را trust و Identify کنید.
3. برای هر دستگاه چک‌لیست: شناسایی صحیح (مدل/نسخه/سریال/نقش)؛ ماتریس قابلیت؛ Backup؛ هر ماژول: Preview → Apply → verify سبز → Backup → Compare؛ تغییر تکراری = skipped؛ خطای عمدی (مثلاً parent ناموجود) = failed/rolled_back؛ قطع شبکه حین اعمال = unknown_state؛ LLDP/CDP.
4. هر ناهماهنگی فرمت (verify شکست‌خورده با تغییر سالم) را با خروجی خام در `nc/simulator.py` و تست مربوط بازتولید و آداپتور را اصلاح کنید.
5. نتیجه را در `docs/STATUS.md` ثبت کنید؛ تا آن زمان هیچ فروشنده‌ای «تأییدشده» نیست.
