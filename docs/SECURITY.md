# امنیت

| موضوع | پیاده‌سازی | وضعیت |
|---|---|---|
| ذخیرهٔ اسرار | DPAPI (ctypes)؛ غیر ویندوز: Fernet با فایل کلید 0600 (فقط توسعه) | DPAPI روی ویندوز واقعی آزموده نشده (CI smoke test آن را بررسی می‌کند) |
| رمز در پاسخ/لاگ/ممیزی | هرگز؛ audit کلیدهای password/secret/token/community/… را `***` می‌کند؛ تست دارد | تست‌شده |
| پشتیبان‌ها | رمزنگاری در دیسک؛ نمایش پیش‌فرض ماسک‌شده؛ «Reveal» ممیزی می‌شود | تست‌شده |
| community SNMP در تغییرها | در DB فقط رمزنگاری‌شده (placeholder در plan) | تست‌شده |
| دسترسی | فقط 127.0.0.1؛ توکن تصادفی ← کوکی HttpOnly SameSite=Strict؛ CSRF با هدر X-NC-CSRF؛ بررسی Host (DNS-rebinding) و Origin؛ بدون CORS | تست‌شده |
| کلید میزبان SSH | پین با تأیید کاربر؛ تغییر = رد اتصال | منطق نوشته شده؛ فقط واحدی (اتصال SSH واقعی آزموده نشده) |
| تزریق CLI | فیلدها با regex سخت‌گیر و بدون خط جدید/نقل‌قول؛ تست دارد | تست‌شده |
| خطاهای داخلی | پاسخ عمومی؛ جزئیات فقط در لاگ | تست‌شده |

**دسترسی LAN:** پیاده نشده (`NC_HOST` غیرمحلی فقط هشدار می‌دهد؛ TLS و ورود کاربر/رمز ندارد). فعال نکنید مگر در شبکهٔ کاملاً مورد اعتماد.
**محدودیت‌ها:** کلید خصوصی با passphrase پشتیبانی نمی‌شود؛ هر کسی که به پروفایل ویندوز شما و فایل `access.token` دسترسی داشته باشد به برنامه دسترسی دارد؛ بازبینی امنیتی مستقل انجام نشده.
