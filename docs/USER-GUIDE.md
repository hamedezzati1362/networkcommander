# راهنمای کاربر و افزودن دستگاه

## افزودن اولین دستگاه
1. **Device Inventory ← Credential profile**: نام، کاربر، رمز (یا کلید خصوصی PEM بدون passphrase) و در صورت نیاز enable secret. رمز رمزنگاری می‌شود و دیگر نمایش داده نمی‌شود.
2. **Add device**: نام، IP، فروشنده، پروفایل. (یا CSV / اسکن CIDR؛ اسکن فقط پورت SSH و بنر را می‌خواند و وارد دستگاه نمی‌شود.)
3. صفحهٔ دستگاه ← **SSH host key** ← «Fetch current key» ← اثر انگشت را با کنسول/برچسب دستگاه مقایسه کنید ← «trust». اگر بعداً کلید عوض شود اتصال رد می‌شود (احتمال MITM یا تعویض دستگاه).
4. **Identify & detect capabilities**: مدل، نسخه، سریال، نقش و ماتریس قابلیت از روی خروجی واقعی دستگاه. اگر فروشندهٔ انتخاب‌شده اشتباه باشد، خطای `not_<vendor>` می‌گیرید.

## پیکربندی
**Configure** ← ماژول ← فرم ← **Preview change** (ریسک، چه کاری، وضعیت فعلی، عملیات) ← **Apply**. نتیجه: connect → backup → apply → verify → save. اگر دستگاه از قبل همان حالت را دارد، چیزی ارسال نمی‌شود (`skipped`).
- ریسک **high** (مثلاً مسیر پیش‌فرض، حذف VLAN): تأیید صریح. **critical** (ری‌بوت، تغییر واسط مدیریتی): تایپ نام دستگاه.
- رول‌بک خودکار فقط برای اشیایی است که همین تغییر ساخته؛ برای تغییر شیء موجود از پشتیبان پیش از تغییر دستی استفاده کنید.
- Cisco: پیش‌فرض فقط running-config؛ گزینهٔ «Save» را بزنید.

## چنددستگاهی
**Multi-device change**: ماژول و مقادیر ← انتخاب دستگاه‌ها ← بررسی سازگاری (ناسازگارها با دلیل) ← حذف دلخواه ← اجرا. high-risk همیشه ترتیبی؛ critical در bulk ممنوع.

## پایش، توپولوژی، عیب‌یابی
- **Monitoring** (در صفحهٔ دستگاه): نمودار CPU/حافظه/دسترس‌پذیری؛ فاصله و آستانه در Settings.
- **Topology**: «Collect LLDP/CDP» همسایه‌ها را از دستگاه‌ها می‌خواند؛ گره‌های خط‌چین دستگاه‌های خارج از موجودی‌اند. هیچ اتصالی ساخته‌شده نیست.
- **Diagnostics**: ping/traceroute و جدول‌های ARP/MAC/route/interface/neighbor **از روی دستگاه** با خروجی خام.
