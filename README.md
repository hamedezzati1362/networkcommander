# Network Commander

پلتفرم گرافیکی مدیریت شبکهٔ چند‌فروشنده (Cisco، MikroTik، Fortinet) که روی همین کامپیوتر ویندوز اجرا می‌شود و با مرورگر باز می‌شود. کاربر دستور CLI نمی‌نویسد؛ فرم می‌پُر می‌کند، پیش‌نمایش می‌بیند و اعمال می‌کند.

> **وضعیت صادقانه:** این نسخهٔ ۰٫۱ یک پایهٔ واقعی و تست‌شده است، نه محصول کامل. فقط با **شبیه‌ساز** و تست‌های خودکار آزموده شده؛ **روی هیچ دستگاه واقعی آزموده نشده است** و نصب‌کنندهٔ ویندوز هنوز روی ویندوز واقعی ساخته/آزموده نشده. جزئیات: [docs/STATUS.md](docs/STATUS.md).

## چه چیزی کار می‌کند (با تست خودکار روی شبیه‌ساز)

- موجودی دستگاه: افزودن دستی، CSV، اسکن SSH روی CIDR، گروه/مکان/برچسب، فیلتر و جستجو.
- اعتبارنامه‌ها: رمزنگاری با DPAPI ویندوز (در لینوکس/توسعه Fernet)، هرگز به UI برگردانده نمی‌شوند.
- SSH با **پین کردن کلید میزبان** (تأیید صریح کاربر؛ تغییر کلید = اتصال رد می‌شود).
- شناسایی واقعی از خروجی دستگاه + **تشخیص قابلیت با دستور‌های probe فقط‌خواندنی** (نه صرفاً ورود موفق).
- موتور پیکربندی: مدل نرمال → مترجم هر فروشنده → پیش‌نمایش (وضعیت فعلی + عملیات) → پشتیبان‌گیری پیش از تغییر → اعمال → **راستی‌آزمایی** → گزارش؛ تشخیص «از قبل برقرار»، رول‌بک خودکار فقط برای اشیای تازه‌ساخته‌شده، رده‌بندی ریسک و تأیید صریح.
- ماژول‌ها: Hostname، VLAN (پایگاه VLAN سیسکو / SVI / VLAN-interface میکروتیک و فورتی‌گیت)، Interface (توضیح، فعال/غیرفعال، access/trunk سیسکو، IPv4، MTU)، Static route، NTP، DNS، Syslog، SNMP v2c، ذخیره/ری‌بوت.
- پشتیبان (رمزنگاری‌شده)، diff، پیش‌نمایش بازگردانی (اعمال خودکار عمداً نیست).
- عملیات چنددستگاهی (ترتیبی/موازی، سقف همزمانی، توقف در خطا، لغو)، قالب‌ها با متغیر و نسخه.
- پایش (دسترس‌پذیری، CPU، حافظه، آستانه، رویداد)، توپولوژی از LLDP/CDP واقعی، عیب‌یابی (ping/traceroute/ARP/MAC/route از روی دستگاه، DNS از این PC).
- ثبت ممیزی بدون اسرار؛ تم تیره/روشن.

آنچه پیاده نشده (OSPF/BGP، ACL/NAT/سیاست فایروال، DHCP، STP، LACP، بی‌سیم، REST/NETCONF و …) در [docs/STATUS.md](docs/STATUS.md) فهرست شده است.

## اجرا برای توسعه

```bash
cd backend && pip install -r requirements-dev.txt && python -m pytest -q      # ۷۰ تست
cd ../frontend && npm ci && npm test && npm run build
cd ../backend && NC_ENABLE_SIMULATOR=1 NC_FRONTEND_DIR=../frontend/dist python -m nc.main
```
